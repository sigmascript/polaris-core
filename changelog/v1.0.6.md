# Changes to v1.0.6

Maintenance release of Polaris Core, preserving the existing public API.

- Updated the development toolchain, including TypeScript, Sass, Webpack, and ts-loader.
- Updated Sass color compatibility handling while retaining the existing customization approach.
- Rebuilt the distributed CSS (including RTL), JavaScript, modular JavaScript, and TypeScript declaration assets.
- Updated package and repository metadata for the SigmaScript GitHub repository transfer.

No new public framework API is introduced by this release.

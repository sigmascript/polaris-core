## Scope and accuracy

The original *Polaris Framework v1.0.0* manual (March 2023) is a historical reference, not a complete or authoritative 1.0.6 API specification. Where component behavior is not yet individually verified, this guide links to the corresponding source rather than inventing options or markup. Detailed component examples can be expanded incrementally after source verification.

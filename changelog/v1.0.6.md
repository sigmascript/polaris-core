# Polaris Core v1.0.6 — Release notes

**Status:** Prepared for release; not yet tagged or published.

This is a compatibility-preserving maintenance and documentation release. No new public framework API is introduced.

## Changes

- Refreshed the pinned development toolchain, including TypeScript, Sass, Webpack and ts-loader.
- Updated Sass color compatibility handling while preserving the existing customization approach.
- Rebuilt distributed CSS (including RTL), JavaScript, modular output and TypeScript declarations.
- Updated package and repository metadata for `sigmascript/polaris-core`.
- Updated the transitive development dependency `fast-uri` to resolve security advisories; npm audits reported zero vulnerabilities after the fix.
- Replaced the outdated project README and introduced structured developer documentation under `/docs/`.
- Added a root `CHANGELOG.md` index while preserving existing version-specific notes.

## Compatibility

This release is intended to preserve the existing Core public API. Confirm final package contents, build results and representative component behavior before publication.
